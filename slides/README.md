# Slides

`Team7_Problem05_movement_anomalies.pptx` — the ~3-minute pitch deck for Problem 05
(*detect unusual changes in movement around the city*).

8 slides: problem & who feels it → four movement sources → how it works (raw →
anomaly → conformed; tech stack; built with Claude Code) → the result (corroborated
anomalies) → playback animation → what WCC could do next → close.

The figures are generated from the committed combined anomaly extracts in
[`../data/combined/csv/`](../data/combined/csv) (cluster map, corroboration chart,
21 April playback filmstrip) — so the deck reflects the actual data, not mock-ups.

Sources shown: WCC transport sensors (real) · Metlink PT (synthetic replay) ·
NZTA highways (real) · WLG flights (real). Synthetic layers are labelled on the slides.
